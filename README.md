# 每日笔记

本地运行的每日记录应用：一日一篇，固定记录未完成的事与今日重要的事。在文档中输入 `/` 打开编辑菜单，插入待办后可在其下填写对应的下一步；正文支持文字格式、链接和拖入图片、音频、视频。旧版独立的下一步记录会保留在未完成的事中，不会自动关联到待办。首次保存新格式时，数据库会保留旧版原始内容。

## 启动

需要 Node.js、npm 和 Docker。进入本目录后运行：

```bash
docker compose up -d
```

```bash
npm install
```

```bash
npm run dev
```

浏览器打开 `http://127.0.0.1:5173`。PostgreSQL 监听本机 55432 端口，API 监听本机 3001 端口。可通过环境变量 `DATABASE_URL` 指定其他 PostgreSQL 连接。

笔记保存在 Docker 的 PostgreSQL 卷中，媒体文件保存在 `data/uploads`。备份时需要同时备份数据库卷和该目录。不要使用 `docker compose down -v`，该命令会删除数据库卷。

打开应用或应用运行期间跨日时，会按浏览器本地日期创建当天笔记；应用未运行时不会在后台生成。切换日期前会保存编辑，保存失败时保留页面并提示。不同页面同时修改同一篇时会提示冲突，需要先复制当前内容再刷新。媒体单个文件最大 100 MiB。
